# Changelog

All notable changes to the SMART public repository are documented here.

## [1.0.0] - 2026-01

### Added

- Initial public release of the SMART GitHub repository.
- Repository structure for scripts.
- Exact PubMed search strategy used for literature retrieval.
- Initial set of 1,110 PubMed records.

---

## [1.1.0] - 2026-06

### Added

- HMDB, KEGG, and PubChem identifier mappings for standardized metabolites.
- Metabolite synonym table for harmonizing alternative metabolite names.
- Metabolite synonym deduplication workflow.
- Additional metadata for standardized metabolite names.
- Improved traceability between source-reported metabolite names and standardized SMART metabolite names.

### Improved

- Refined metabolite nomenclature harmonization rules.
- Reduced duplicate metabolite entries caused by spelling variants, abbreviations, and synonymous names.
- Improved consistency of metabolite naming across studies.
- Improved compatibility of SMART metabolites with external metabolite databases.

---
## [1.2.0] - 2026-09

### Added

- Expanded README documentation and repository navigation.
- Added analysis and visualization scripts.
- Improved repository organization to support transparency, reproducibility, and data reuse.
