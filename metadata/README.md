# Metadata

This directory contains the controlled metadata and harmonization resources used by SMART.

| File | Purpose |
|---|---|
| `01_Data_dictionary.xlsx` | Field definitions, curation level, normalization rules and examples |
| `02_Data_template.xlsx` | An example for data extracting |
| `03_Metabolite_identifiers.csv` | HMDB, KEGG and PubChem mappings |
| `04_Metabolite_synonyms.csv` | Source-reported synonym to standardized-name mappings |

Important: external identifiers are preserved from the supplied curation table. Users performing identifier-sensitive analyses should verify the relevant subset against the current external database release.
